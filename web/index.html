Learn how AI works

Each demo shows one idea about AI, and you can try it yourself. There is nothing to install and no sign-up. Nothing you type leaves your device.

The first demo takes a moment to get ready (about 13 MB). After that, it is quick. Demos 02 and 06 need a bigger download, so they ask first.

Demo 01 How AI reads words AI cuts words into small pieces called tokens. Then it guesses the next piece. Try it with your own sentence. Demo 02 How AI looks things up Before AI answers, it can look up the answer first. See when it finds the right part, and when it does not. Demo 03 Watch an AI agent think An agent is an AI that can use tools, like a calculator. Watch it pick a tool, and sometimes pick the wrong one. Demo 04 Who should handle this? AI can send your request to the right helper. See how it chooses, and when it chooses wrong. Demo 05 Why AI forgets AI can only remember so much at once. When its memory is full, the oldest messages are lost. Watch it happen. Demo 06 When AI makes things up Ask a real AI about a made-up town, and it makes up answers. See what changes when it reads about the town first. Demo 07 Ask AI better Ask clearly, and AI gives a better answer. See 4 real examples, then check your own question. Demo 08 Hidden orders in documents A hidden order in a document can trick an AI. See a filter catch it, and then miss it. Demo 09 Hide private info from AI A "black marker" hides private details before AI sees them. See what it hides, and what it misses. Demo 10 Two agents, one job Two AI agents pass a bug report from one to the other. Watch each step, and see where it can go wrong.
